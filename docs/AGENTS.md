# 文档归属

[文档导航](README.md)按用途组织入口。采用 [maintain-docs](../.agents/skills/maintain-docs/SKILL.md)；文档分工、创建门槛和交付规则分别见[事实归属](../.agents/references/documentation.md)与[文档生命周期](../.agents/references/document-lifecycle.md)。

- `architecture.md` 说明当前职责、依赖和扩展入口；`reading.md` 说明文章写法、阅读功能与限制；`development.md` 说明开发、维护工具和检查。
- `research/` 保留框架、主题和设计参考的证据，明确原始核查日期；不在研究材料中维护当前配置或施工计划。
- `.agents/notes/` 保存实际决策理由和代价，不把当前 API 全文复制到记录中。
- 本地 `papers/` 不属于公开文档，不加入导航、检查输入或 Git 提交。
- 同一事实只在所属页面完整维护；合并前迁入独有证据、负结果与限制，再删除旧正文并修复入链。
- 段落不手工折行。移动与改名后运行文档检查；不手改生成物，不自动按篇幅删字。

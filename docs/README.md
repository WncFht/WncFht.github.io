# 文档导航

维护这个静态研究博客时，先按任务选择入口。当前使用说明与历史调研分开维护，文档目录本身不作为网站文章发布。

| 要完成的事                       | 入口                                                        |
| -------------------------------- | ----------------------------------------------------------- |
| 安装、运行、检查或配置 Git hooks | [开发与维护](development.md)                                |
| 理解页面、内容管线和扩展边界     | [站点架构](architecture.md)                                 |
| 写公式、代码、图片和专题元数据   | [文章与阅读功能](reading.md)                                |
| 比较框架、Astro 主题与个人站点   | [框架与主题选型](research/2026-11-09-博客框架与主题选型.md) |
| 查询设计来源、组件源码与许可     | [阅读体验设计参考](research/2026-11-09-阅读体验设计参考.md) |
| 复核已完成架构整理的检查证据     | [架构审查](research/2026-11-09-架构审查.md)                 |
| 编写或维护长期决策理由           | [Agent Notes](../.agents/notes/README.md)                   |

研究材料保留原始核查日期，版本、维护信号和页面观察只代表对应快照。当前配置与能力以使用指南、源码和测试为准。

原根目录 `research/` 已合并到这里：框架迁移和 Astro 生态两篇合为选型报告；前端调研和视觉复用两篇合为设计参考；旧阅读实现说明的有效约束进入阅读指南、架构与设计参考，过时施工记录不再维护。原架构说明中的验证流水迁入日期明确的审查报告。

文档归属与更新规则见 [AGENTS](AGENTS.md)。本地未提交论文材料不进入公开导航。

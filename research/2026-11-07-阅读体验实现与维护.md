## 使用约定与边界

### 图片与公式

图注依次取 Markdown 图片 title、alt，以纯文本生成，alt 保留。同一段里连续的独立图片组成图组；混合文字、带链接的图片保持原结构。查看器支持点击、Enter、空格、Esc 与图组前后切换。图片加载失败显示错误说明，`data-no-zoom` 可禁用单张图片。

本地图片继续使用 Docusaurus 图片变换与尺寸处理。远程图片、手写 MDX 图片需作者显式提供宽高，不宣称所有远程图片都自动避免布局变化。docs 和 blog 共用数学插件，KaTeX CSS 从 npm 依赖随站点托管。

### 设置与专题

偏好保存在当前浏览器 `site-reader-v1`，首屏脚本与 React 校验同一组合法值；存储被禁用时仍可阅读。纯净模式保留退出按钮，宽度设置受屏幕和侧栏约束，在桌面及纯净模式下更明显。

`collections` 表示归属，`issue` 表示期号，`series_order` 表示明确顺序，后两者只接受正整数。无顺序的文章按日期浏览，不生成顺序关系。同专题不要复用顺序号；多个专题需要不同顺序时，应扩展为每专题独立顺序数据。

### 分享、预览与导出

站内预览只读取已公开收录文章的元数据，不请求任意外站摘要。悬停/聚焦显示，Esc、离开、失焦和滚动关闭；触屏直接访问原链接。

段落分享要求同一段内至少 4 个字符，链接包含 1 起始段落位置与选中文字的前 80 个字符。打开后先验证该位置，再尝试唯一文字匹配；内容已变或匹配不唯一时不跳到错误段落。分享仅产生本地复制操作，不上传选中文字。它适合阅读定位，不能代替永久引用编号。

Mermaid 提供 SVG 下载，不嵌入网站字体，跨设备字形可能变化。全屏只保留一个 SVG 实例，避免重复 ID；返回后恢复页内图，语法错误时可查看源码或重试。
